# Porch Thief System

Rob packages at doors and earn money in FiveM.

## Features

- Spawns packages at predefined door locations
- Allows players to rob packages and earn money
- Configurable spawn intervals, package models, and rewards

## Requirements

- FiveM server
- ESX Framework
- MySQL-Async

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start porchthief` to your server.cfg file

## Usage

- Packages will spawn at the configured door locations
- Players can approach a package and press E to rob it
- Players will receive a random amount of money as a reward

## Configuration

Edit the `config.lua` file to customize:

- Package spawn interval
- Package spawn radius
- Package models
- Package health
- Package rewards
- Door locations
